# Ball Breaker

This is my first game! I made it in 2019 using GameMaker 8.1.

![Ball Breaker cover](ball%20breaker.png)

## Play the game

Open [Ball Breaker.exe](Ball%20Breaker.exe), click **Download raw file**, and run it on Windows.

## GameMaker project

You can open [Ball Breaker.gm81](Ball%20Breaker.gm81) in GameMaker 8.1. The [backup file](Ball%20Breaker.gb1) is here too.
